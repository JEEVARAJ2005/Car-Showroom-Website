# Apex Motors – Car Showroom (React)
Run: `npm install` then `npm run dev`.
Concept → file map: Redux `store/`, useContext `context/`, custom hooks `hooks/`,
nested routes `App.jsx` + `pages/Services.jsx`, useParams `CarDetails`/`Services`,
useSearchParams `Cars`/`Profile`, CRUD + useReducer `pages/Profile.jsx`,
validation `utils/validate.js` + `Contact`, API `hooks/useFetch.js` (Home, About), useRef `Cars`/`Contact`/`Profile`.
